# Grimdark Mystery Shop Web App 🖤🏰

An atmospheric, dark-fantasy themed RPG storefront and inventory management web application built with Python and Django. This project features dynamic session-based state management, transaction logic validation, and a custom medieval-inspired UI design.

---

## 🌌 Features

* **Atmospheric Intro Page:** An identity ledger gate set outside an immersive volcanic cavern entrance where players register their character names.
* **Dynamic Session Tracking:** The application tracks active player state across pages, securely controlling access to the storefront.
* **Interactive Catalog Storefront:** A database-backed shop clerk interface running fully validated backend transaction mechanics.
* **Secure Vault Audit:** A clean, organized stone treasury view where players can view their current inventory holdings.
* **Mobile-Responsive Retro UI:** Immersive CSS layouts using medieval-style color palettes, custom typography, and responsive grid layouts.

---

## 🛠️ Tech Stack

* **Backend Framework:** Django 6.0+
* **Language:** Python 3.13+
* **Database:** SQLite (Local development)
* **Frontend:** HTML5, Semantic CSS3, Django Template Engine
